# DukaanLite---Kirana-Digital-Catalog-WhatsApp-Order-Flow
DukaanLite gives a small kirana store a simple online catalog. The shopkeeper adds products with price, unit, category, photo and stock status. Customers open the shop link on their phone, browse or search, add items to a cart, and tap Order on WhatsApp. 

[![Live demo](https://img.shields.io/badge/%E2%96%B6%20Live%20demo-open%20the%20website-22c55e?style=for-the-badge)](https://dhruvadasaraju.github.io/DukaanLite---Kirana-Digital-Catalog-WhatsApp-Order-Flow/)

**Live demo:** [dhruvadasaraju.github.io/DukaanLite---Kirana-Digital-Catalog-WhatsApp-Order-Flow](https://dhruvadasaraju.github.io/DukaanLite---Kirana-Digital-Catalog-WhatsApp-Order-Flow/)

The website runs in your browser and keeps the shop's data there, so each visitor gets their own demo shop.
Try **Shop**, then **Shopkeeper → Orders board** in another tab. The code is in the [`dukan lite`](dukan%20lite) folder;
see its README to run it with the Node.js + MongoDB server for shared, live orders across devices.
